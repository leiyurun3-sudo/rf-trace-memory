# Qwen 本地诊断：26 次推理

只读取现有模型和实验图片，不重新生成图像，不下载模型，不覆盖现有评分。结果写入带时间的新目录并自动打包。

上传 ZIP 到 `/root/autodl-tmp` 后：

```bash
cd /root/autodl-tmp
unzip -o A_Qwen_Diagnostic.zip
cd A_Qwen_Diagnostic
nohup bash run.sh > diagnostic.log 2>&1 &
tail -f diagnostic.log
```

这是诊断，不是新一轮正式评分。26 次推理只比较同一模型的输入与提示；无需重跑 520 张。已完成的评测不会受影响。运行前确认此前评分已结束，避免两个模型同时占显存。

## 检查什么

1. 红/蓝方块单图、双图、交换顺序、相同双图：答案已知，检查视觉输入与顺序。记录视觉 token、image_grid_thw、pixel_values 形状和逐图张量校验值。
2. 三个已误判的真实源（白墙、月亮、猕猴桃）：无目标文本描述、两图观察、旧评分提示原样重放、观察优先提示、旧/新规则提示。相同图片不应凭空出现请求的变化。
3. 两对真实编辑图：检查差异输入是否被使用，不预设哪个方法应赢。
4. 相同双色输入用显式 slow processor 再跑一次，与当前默认处理器比较。

## 如何定位

- 视觉张量缺失或 token 数不匹配：处理器/传图接口故障。
- 单图颜色正确、双图顺序错误：多图理解或顺序处理需查；用逐图张量校验值区分输入倒序与模型判断倒序。
- 无目标文本能看对，旧提示判断错误，新提示恢复：提示诱导是主要线索。
- 简单颜色正常，但简化提示仍把原图说成改好：该模型在真实编辑判断上不足，需要进一步校准或更换本地裁判。
- 主体/图案仍被全部排除：规则定义失败，不能启动全量评分。

人工已核查的事实用于诊断对照，不会写入或替换模型答案。保存每次原始回答；格式合格不记作判断正确。此包尚未在服务器 GPU 运行，运行结果才回答具体故障层。

模型接口参照 [Qwen2.5-VL 4.55.4 文档](https://huggingface.co/docs/transformers/v4.55.4/en/model_doc/qwen2_5_vl)。此小样本曾用于诊断，后续正式校准需另设未参与提示调整的控制样本。
