**Positioning.** Existing work supplies source-feature injection, mutual KV retrieval, spatial blending and attention-mass preservation. The concrete R80 hypothesis is that allocating a fixed trajectory-correction RMS to useful spatial/frequency support, together with a separately controlled text-preserving KV write, improves fine-detail retention during successful edits. The reviewed methods do not establish this particular allocation rule; broader priority would require checking trajectory-error correction literature, especially Direct Inversion. This pass establishes mechanism differences and a validation path.

**Minimal decision experiment (proposed).** Factor uniform/routed correction × memory off/on; add unnormalized, shifted and area-matched random routes, then KV pairing controls. Use identical source images, prompts, seeds, weights, editable support and shared-path settings for mechanism comparisons. For external pipelines retain their native inversion and report total NFE, time and peak VRAM; include a compute-matched operating point. Score edit correctness first, then inside-edit-region detail/identity, unedited content, boundaries and paired uncertainty across cases. Success requires routed correction to beat uniform and wrong-location controls at matched edit success and uncapped RMS, with a repeatable memory benefit. If normalization alone explains the gain, retain normalization and simplify routing; if only manual ROI works, develop support selection and report its annotation dependence. Select **FireFlow alongside the closest-method ReFlex baseline**; RF-Edit is a useful additional V-only/solver comparison, while MasaCtrl is primarily a mechanism precedent.

**Sharper positioning.** R80's candidate advance is allocating a matched correction budget independently of edit permission and memory writes. The two reviewed methods establish masking, source-trajectory preservation and feature injection; neither reviewed mechanism specifies R80's online RMS ratio. Added value requires correct routing to outperform uniform and wrong-location controls at matched edit success. A second scalar normalization alone establishes amplitude control, not useful spatial allocation.

**Baseline priority update.** DirectEdit is the more decisive mechanistic FLUX comparator; FireFlow remains the inexpensive external efficiency baseline. DirectEdit supports supplied masks, allowing the core comparison to use a common M without MLLM/SAM mask-generation differences. Its source/target branches may be batched in one transformer call, so report processed examples or sample-equivalent NFE alongside call count. The official implementation's explicit source copying means source-path equality by itself cannot demonstrate superior learned reconstruction.


## Parent synthesis: Direct Inversion and FlowEdit

- **Direct Inversion**, [primary methods and Algorithm 1](https://arxiv.org/html/2310.01506v1), section 4.2: compute stepwise source-branch offsets from the stored inversion path; correct the source reconstruction branch while maintaining the edited target branch. The mechanism is an important correction precedent. R81's target-state correction allocation is a different operator; evaluate its benefit rather than attributing all source-reference correction to this project. The paper introduces PIE-Bench, 700 image-edit pairs in ten categories with evaluation masks.
- **FlowEdit**, [primary methods and Algorithm 1](https://arxiv.org/html/2412.08629v2), sections 4–5, equations 5–9: construct coupled source/target noisy states from the current edit and a noised source, integrate their velocity difference, and optionally average noise samples. This is an inversion-free semantic editing comparator. Its n_max changes the working point; source MAE alone does not determine successful editing. R81 fixes N26 and source/target guidance 1.5/5.5 across the independent pilot.

Across these eight method readings (RF-Edit/RF-Solver, ReFlex, MasaCtrl, FireFlow, DiffEdit, DirectEdit, Direct Inversion and FlowEdit), source feature reuse, masking, and trajectory anchoring have clear precedents. The proposed added value is spatial allocation of an explicit online correction RMS budget, assessed together with a target-text/image-mass-preserving readout. R81 tests annotation-independent support on new sources, normalization dose, readout, support perturbation, and two external algorithms. It implements RF-Edit now; DirectEdit and ReFlex are the next closest comparisons after a candidate passes this independent pilot. The literature table records the sections read, not an assertion that every page of all eight papers was read.
